## 2. 見た目のルール
チーム内で統一感のあるサイトを作成するため、以下のルールに従う。
### 基本デザイン
| 項目 | ルール |
|---|---|
| 背景色 | #A88C7D |
| メインカラー | #F4E8D8 |
| サブカラー | #4F382E |
| 文字色 |  #000000 |
| フォント | Noto Serif JP(明朝体) |
| フォントサイズ | 16px |
### レイアウト・共通ルール
- ページ全体のレイアウトを統一する。
- ボタンの色や形を統一する。
- 見出しのデザインを統一する。
- 余白や配置をできるだけ統一する。
- 共通のデザインはBootstrapを使用する。
### その他のルール

## 3. マージルール
GitHubでのPull Requestのマージ条件を記載する。
| 項目 | 設定 |
|---|---|
| 必要なApprove数 | 1 |
| Approveなしでのマージ | 不可 |
### マージ時の注意事項
- 作業内容をPull Requestに記載する。
- マージ前に担当者以外のメンバーがコードを確認する。
- Approveを1人以上から受けてからマージする。
- コンフリクトが発生した場合は解消してからマージする。
